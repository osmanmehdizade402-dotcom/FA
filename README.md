## Tövsiyə olunan ad: **MərdEv**

Rəsmi ad: “MərdEv Əmlak” MMC. Şüar: *Mərdəkanda mərd sövdələşmə*.

- “Mərd” Mərdəkanı xatırladır və düzlük, sözünün üstündə durmaq deməkdir.
- “Ev” işi dərhal izah edir.
- İnternetdə “ə” hərfi olmadığı üçün `mardev.az` və `merdev.az` ikisini də götürün.

Alternativlər: Mehdizadə Əmlak, Qala Əmlak, Xəzər Sahil Əmlak.
“Fədai Əmlak” variantına diqqət: “fədai” sözü Qarabağ kontekstində erməni silahlı dəstələri (fidayi) ilə də əlaqələndirilir.

## Qısa yol xəritəsi

1. **Hazırlıq:** biznes modeli, FS yoxsa MMC, ad yoxlaması (vergi orqanı, copat.gov.az, domen), ASAN imza, hüquqi ünvan.
2. **Qeydiyyat:** e-taxes.gov.az və ya ASAN Xidmət, VÖEN; fəaliyyət kodu **68.31**; vergi rejimi; bank hesabı; mühasib; kassa; Maliyyə Monitorinqi tələbləri.
3. **Brend və ofis:** loqonun son halı, ticarət nişanı (sinif 36, 35), lövhə icazəsi, çap materialları, Google Xəritə, elan saytları.
4. **Sənədlər:** vasitəçilik müqaviləsi, baxış aktı, beh qaydası, obyekt yoxlama siyahısı, CRM, işçilərin rəsmiləşdirilməsi.
5. **İlk 90 gün:** 20 obyekt, peşəkar şəkil, notarius və bank əlaqələri, yay mövsümünə hazırlıq, aylıq hesabat.

Ətraflı izah və risklər `sistem/index.html` səhifəsindədir.
